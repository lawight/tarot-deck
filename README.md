## 一、世界观

这副牌在跳蚤市场躺了三十年，纸边发黄，缺了张「世界」。

买下它的年轻人叫**周昱**，二十四岁，在做一份他不喜欢的工作。

那天晚上他在出租屋的灯下摊开牌，翻到第二张的时候——

**牌上的人动了。**

不是幻觉。她坐在那里，低头看着自己的手，然后抬起头，看了他一眼。

> **这副牌不画神。它画的是牌见过的人。**
>
> 一百年来，凡是被这副牌"记住"的人，都活在牌里。
> 牌记得她们的样子、她们的手、她们最后一眼看的方向。
>
> **翻开一张，就是让一个人重新活一次。**

周昱翻完了二十一张。

第二十二张不在牌里——**那张「世界」，在他手上。**

## 五、设计原则

1. **年龄分布**：18–38 全覆盖，每个年龄段至少 2 人
2. **职业不重复**：22 个人 22 种活法，没有一个重复
3. **反刻板**：每张牌的女性都不完全符合"传统牌义"——**牌义是别人给的，活法是她自己的**
   - 例如「死神」不是死亡，是**陪着别人走完最后一程的人**
   - 「恶魔」不是邪恶，是**把嗓子里那点东西喊出来的人**
4. **全员成年**：最年轻 18（刚成年），最年长 38
5. **无色情**：这是群像与命运的故事，不是身体的故事
